# PyTrace Examples

This directory contains example scripts demonstrating PyTrace capabilities.

## Server & Dashboard Example

The quickest way to see PyTrace in action is to run the example server and dashboard together.

### Prerequisites

- Python 3.12+
- Poetry (for dependency management)
- Node.js 16+ and npm (for the dashboard)

### Setup

1. **Install Python dependencies:**
   ```bash
   cd /path/to/pytrace
   poetry install
   ```

2. **Install dashboard dependencies:**
   ```bash
   cd dashboard
   npm install
   cd ..
   ```

### Running the Example

#### Step 1: Start the Example Server

The example server generates sample trace data and starts the Flask API:

```bash
poetry run python examples/server.py
```

You should see output like:
```
Generating sample trace data...
 * Running on http://127.0.0.1:5000
```

The server is now running on `http://localhost:5000` with sample traces loaded.

#### Step 2: Start the Dashboard (in another terminal)

```bash
cd dashboard
npm run dev
```

You should see output like:
```
  ➜  Local:   http://localhost:5173/
```

#### Step 3: Open the Dashboard

Visit `http://localhost:5173` in your browser to see the dashboard displaying:

- **Traces View**: All traces generated by the example
- **Operations Dashboard**: Statistics on operations (API calls, database queries, cache lookups)
- **Latency Analysis**: Percentile latency metrics (p50, p95, p99)
- **Error Analysis**: Error rates and error traces

### What the Example Generates

The example server creates 5 sample traces, each simulating a realistic application flow:

```
API Request
  ├── Database Query (with intentional errors on some traces)
  └── Cache Lookup
```

Key features in the sample data:
- **Mixed Success/Error Traces**: ~30% of traces contain errors
- **Nested Spans**: Shows parent-child span relationships
- **Events & Attributes**: Includes events with attributes (endpoint, table, status code, etc.)
- **Variable Latency**: Database queries have intentional delays to show latency variation

### Dashboard Features to Explore

1. **Traces Tab**: Browse all generated traces, see their status and span counts
2. **Operations Tab**: View statistics for each operation type:
   - Call count
   - Error rate
   - Average, min, and max duration
3. **Latency Analysis**: See 50th, 95th, and 99th percentile latencies
4. **Error Analysis**: Filter and view only error traces
5. **Trace Explorer**: Click on any trace to see full details and span relationships

### Troubleshooting

**Dashboard shows blank/no traces:**
- Ensure the Flask server is running (check terminal output for "Running on...")
- Check that both services are on the correct ports (Flask: 5000, Vite: 5173)
- Check browser console for CORS or connection errors

**Server won't start:**
- Run `poetry install` to ensure all dependencies are installed
- Verify Flask is installed: `poetry run python -c "import flask; print(flask.__version__)"`

**Dashboard won't load:**
- Run `npm install` in the `dashboard/` directory
- Ensure Node.js 16+ is installed: `node --version`
